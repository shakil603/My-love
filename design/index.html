01 · Design Language

“Aurora” design system

A warm rose-to-violet aurora gradient carries emotion (love, connection); deep ink neutrals carry trust (work, business). Soft 20–28 px radii, airy 4-pt spacing, Sora for display, Plus Jakarta Sans for UI. WCAG-AA contrast throughout; full RTL & 40+ language readiness.

07 · How it gets real

Open-source backbone, user-powered edge

The design above maps to a practical, buildable stack: Kotlin + Jetpack Compose (Material 3) on Android; Matrix (Synapse/Dendrite) for E2E-encrypted messaging & federation; ActivityPub for the global social graph; open-source media pipeline (Thumbor / LibreOffice headless / pdf.js / ExoPlayer) to generate previews for 300+ file formats; MinIO or users' own devices (P2P via WebRTC + libtorrent) for storage. Everything self-hostable — the platform can run on community servers or on the users' own hardware.

Messaging

Matrix protocol · E2E (Olm/Megolm) · voice & video via WebRTC · offline queue · federated worldwide

Social + Dating

ActivityPub feed · on-device match scoring · consent-first visibility · verified profiles

Files & Previews

Any type, chunked upload · client-side thumbnails · server render for PDF/Office/CAD · in-app viewer

Infrastructure

Self-hostable Docker stack · or P2P device mesh · nothing proprietary, nothing locked in
